Contraceptive methods

Idea

A method selector should be a generic class (an intervention?). We want the existing matrix-based method and the new duration-based method to both be instances of this.

SimpleChoice Choose a method based on age and previous method.
StandardChoice Choose a method based on age, education, wealth, parity and prior use.

ContraceptiveChoice

methods.ContraceptiveChoice(pars=None, **kwargs)

Base class for contraceptive choice modules.

A choice module owns the list of available methods and decides, for each woman at each decision point, whether she uses contraception and which method. Subclasses differ only in how that probability is computed; see RandomChoice, SimpleChoice and StandardChoice.

The module is reached at sim.connectors.contraception during and after a run. Note this is distinct from the FP module itself, which lives at sim.people.fp.

Method

methods.Method(
    name=None,
    label=None,
    idx=None,
    efficacy=None,
    modern=None,
    dur_use=None,
    rel_dur_use=1,
    csv_name=None,
    _source_dur=None,
)

A contraceptive method.

Methods are held by a contraceptive choice module, which decides who uses which one. A woman re-chooses when her current method’s dur_use elapses, so dur_use shapes the long-run method mix as much as efficacy does.

Note that name and label are not interchangeable: code indexes the method dictionary by name (cm.methods['inj']), while interventions that take method identifiers look them up by label ('Injectables').

Parameters

Name Type Description Default
name str short identifier used in code, e.g. 'inj' None
label str display name used in plots and interventions, e.g. 'Injectables' None
idx int position in the method list; set automatically when added to a module None
efficacy float proportional reduction in conception probability while using None
modern bool whether this counts towards modern contraceptive prevalence (mCPR) None
dur_use Dist distribution of duration of use before re-choosing None
rel_dur_use float multiplier on dur_use, for scaling a copied method 1
csv_name str name used for this method in the input data files None

Example:

```python
import starsim as ss
import fpsim.methods as fpm

dmpasc = fpm.Method(name='dmpasc', label='DMPA-SC', efficacy=0.983, modern=True,
                    dur_use=ss.lognorm_ex(ss.years(2), ss.years(1)))
```

Note

To introduce a method partway through a simulation, use the add_method intervention rather than building the method list by hand.

RandomChoice

methods.RandomChoice(pars=None, **kwargs)

Choose a method uniformly at random.

Intended for testing model mechanics, not for producing realistic method mix. Because it needs no fitted data, it is the only choice module that accepts a method list containing methods with no per-method data – useful when checking that a new method behaves sensibly before wiring up its uptake.

Parameters

Name Type Description Default
pars dict parameters for the choice module None
kwargs dict passed to ContraceptiveChoice {}

Example:

```python
import fpsim as fp
import fpsim.methods as fpm

methods = fpm.make_methods()
methods += fpm.Method(name='dmpasc', label='DMPA-SC', efficacy=0.983, modern=True,
                      dur_use=ss.lognorm_ex(ss.years(2), ss.years(1)))
sim = fp.Sim(location='kenya', contraception_module=fpm.RandomChoice(methods=methods))
```

SimpleChoice

methods.SimpleChoice(
    pars=None,
    location=None,
    data=None,
    contra_mod='simple',
    **kwargs,
)

Choose a method based on age and previous method.

Uses location-specific fitted data, so it must be initialized with either a location string or a data dictionary. Because the fit is per method, passing a method list that contains a method with no fitted duration data raises an IndexError; to introduce a new method use the add_method intervention with copy_from, which inherits an existing method’s behavior.

Parameters

Name Type Description Default
pars dict parameters for the choice module None
location str location whose fitted coefficients to load, e.g. 'kenya' None
data dict pre-loaded data, used instead of loading from location None
contra_mod str which fitted coefficient set to use 'simple'
kwargs dict passed to RandomChoice {}

Example:

```python
import fpsim as fp
import fpsim.methods as fpm

sim = fp.Sim(location='kenya', contraception_module=fpm.SimpleChoice(location='kenya'))
```

StandardChoice

methods.StandardChoice(
    pars=None,
    location=None,
    data=None,
    contra_mod='mid',
    **kwargs,
)

Choose a method based on age, education, wealth, parity and prior use.

This is the default choice module, used when no contraception_module is passed to Sim. It extends SimpleChoice with education and wealth, and carries the same requirement for per-method fitted data.

Parameters

Name Type Description Default
pars dict parameters for the choice module None
location str location whose fitted coefficients to load, e.g. 'kenya' None
data dict pre-loaded data, used instead of loading from location None
contra_mod str which fitted coefficient set to use 'mid'
kwargs dict passed to SimpleChoice {}

Example:

```python
import fpsim as fp

# Used automatically, so these are equivalent
sim = fp.Sim(location='kenya')
sim = fp.Sim(location='kenya',
             contraception_module=fp.StandardChoice(location='kenya'))
```
